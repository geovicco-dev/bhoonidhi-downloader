# `bhd`

Search, save, and download satellite imagery from the Bhoonidhi Earth Observation portal.

**Usage**:

```console
$ bhd [OPTIONS] COMMAND [ARGS]...
```

**Options**:

* `--help`: Show this message and exit.

**Commands**:

* `version`: Package version.
* [`auth`](auth.md): Authenticate with Bhoonidhi Portal.
* [`archive`](archive.md): Browse available satellites and sensors.
* [`query`](query.md): Search and manage saved queries.
